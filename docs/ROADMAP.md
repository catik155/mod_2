# Cyber Arena implementation roadmap

## Phase 1 — Core gameplay foundation
- [x] Fabric 1.21.1 project scaffold and Java 21 build
- [x] Server-authoritative persistent player profiles
- [x] Zero-start economy: 0 credits, 0 reputation, no upgrades
- [x] One-time starter contracts and fictional site incidents
- [x] Simulated player-vs-player breach with cooldown, firewall, alert and data shard rewards
- [x] Persistent firewall and attack-automation upgrade levels

## Phase 2 — Operator workstation
- [ ] Interactable computer block/item and terminal screen
- [ ] NEX command history, autocomplete, help and readable error feedback
- [ ] Virtual file system, inventory and data vault
- [ ] Script builder with safe, in-game automation routines

## Phase 3 — Simulated network world
- [ ] Expand fictional .arena network graph and access tiers
- [ ] Fictional websites with services, vulnerabilities as game stats, and security incidents
- [ ] Recon, access, extraction and cleanup as turn/tick-based game actions
- [ ] NPC-owned sites and rotating contracts

## Phase 4 — Automation and defense
- [x] Upgradeable attack automation and firewall foundations
- [ ] Defensive rules, honeypots, backups, rate limits and auto-response
- [ ] Programmable routines with resource limits, cooldowns and clear logs
- [ ] Trace, alert, detection and recovery systems

## Phase 5 — Multiplayer competition
- [x] Server-side validation and online-target-only simulated PvP action
- [ ] Protection windows, consent/arena rules and anti-grief safeguards
- [ ] Leaderboards, groups, tournaments and team roles
- [ ] Balanced rewards, risk and matchmaking

## Phase 6 — Content and release
- [ ] Story campaign, NPC rivals, daily contracts and random cyber incidents
- [ ] UI, sounds, particles, localization and accessibility polish
- [ ] Multiplayer, persistence, economy and exploit-resistance tests
- [ ] Publish versioned remapped JAR after CI succeeds

## Simulation boundary
All hacking, theft, attacks, websites, computers, addresses and defenses are fictional game-state operations inside Minecraft. No real network access, external target scanning, OS command execution, real exploit payloads or real data theft.
